# Mila World Modelling Reading Group

The Mila World Modelling Reading Group meets weekly at [Mila](https://mila.quebec/) to discuss
recent work on world models.

**Website:** https://mila-world-modelling.github.io/world_modeling_rg/
**Contact:** use the [contact form](https://mila-world-modelling.github.io/world_modeling_rg/contact/)

## Updating the site

Sessions go in `data/sessions.yaml`, organizers in `data/organizers.yaml`, and organizer photos in
`assets/images/organizers/` (named by first name). Pushing to `main` publishes the changes.
